# 보안 및 거버넌스 - 정의

Claude Code 운영 환경에서 보안 및 거버넌스는 권한 관리, 시크릿 보호, 안전 장치 구축을 포함합니다. Hooks, permissions 설정, MCP 스코프 관리를 통해 다층 방어 체계를 구축합니다.

# 관련 라이브러리 및 SDK - 정의

MCP 서버 개발 및 Claude Code 확장을 위한 공식 SDK와 커뮤니티 라이브러리 목록입니다. 각 SDK는 MCP 프로토콜을 구현하여 자체 서버를 구축할 수 있게 합니다.

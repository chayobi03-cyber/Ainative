# MCP 설정법 - 예외 사례

- local 스코프는 프로젝트별이므로 다른 프로젝트에서는 미표시
- `.mcp.json` 변경 후 세션 재시작 필요
- OAuth 서버는 `/mcp`에서 Authenticate 선택하여 브라우저 로그인
- 서버 이름 중복 시 `--scope`로 구분하여 제거

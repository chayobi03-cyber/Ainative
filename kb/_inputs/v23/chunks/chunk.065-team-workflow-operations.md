# 팀 워크플로우 - 운영 가이드

- 에이전트 설정 파일을 버전 관리하여 팀 일관성 유지
- 팀 위키에 각 에이전트의 용도, 사용 시기, 프롬프트 예시, 한계 기록
- 1-2개의 전문 에이전트로 시작, 실제 성능 기반 개선
- 서브에이전트에 완전한 컨텍스트 전달 (메인 대화 기록 접근 불가)
- 구조화된 데이터 반환 (JSON이 산문보다 파싱 용이)
- 독립 작업은 병렬 실행, 결과는 메인 컨텍스트에서 취합

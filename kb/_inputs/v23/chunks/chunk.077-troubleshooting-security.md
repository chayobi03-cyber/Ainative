# 트러블슈팅 가이드 - 보안 고려사항

- 트러블슈팅 중 시크릿을 로그에 출력하지 않도록 주의
- `curl`로 서버 응답 확인 시 토큰이 로그에 남지 않도록 주의
- 디버깅을 위해 환경 변수를 일시적으로 설정한 경우 복구

# Hooks 설정법 - 정의

Hooks 설정은 `.claude/settings.json`에 이벤트-매처-핸들러 구조의 JSON을 작성하여 Claude Code의 라이프사이클 이벤트에 자동화를 연결하는 과정입니다.

### B-1 — 병합 로직의 aliasing 버그로 청크 2개 유실 (심각)

```python
buckets[-2] += buckets.pop()      # 결함
```
`buckets.pop()`이 먼저 평가돼 리스트가 줄어들면서 `-2`가 한 칸 밀린다. 결과적으로
**다른 버킷을 덮어쓰고** `chunk.073`, `chunk.074`를 통째로 유실시켰다.

- 검출: T-06 중복 시험이 Jaccard **0.986** 쌍을 잡아냄 → 수동 diff로 원인 규명
- 조치: `merge_undersized()`로 재작성, 양수 인덱스 + 새 리스트 반환
- **재발 방지**: 빌더에 보존 불변식 `assert`를 심었다(T-10). 입력 조각 ID 집합과 출력
  버킷의 조각 ID 집합이 정확히 일치하지 않으면 빌드가 실패한다.

이 버그는 조용했다. 출력 청크 수는 정상으로 보였고, 중복 시험이 없었다면 넘어갔을 것이다.

### B-2 — 꼬리 버킷만 병합해 중간에 소형 버킷 잔존

B-1 수정 후 채움 청크(F-1)를 제거하자 앞쪽 버킷이 128토큰으로 홀로 남았다.
꼬리 하나만 처리하던 로직의 한계. 인접 버킷 흡수를 반복하는 방식으로 일반화했다.

### B-3 — 카탈로그 섹션에서 retrieval_questions 미생성 5건

섹션 템플릿에 없는 `reference-servers` 같은 섹션이 질문 없이 통과했다.

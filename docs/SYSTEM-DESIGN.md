# 시스템 설계 — 지식 베이스에서 사내 참모로

## 목표

수십 개의 사내 AI 협업 프로젝트가 이 저장소를 **참고처가 아니라 참모**로 쓴다.
지침을 받아 가고, 겪은 것을 되돌려 보내고, 그 신호로 지침이 좋아진다.

이 문서는 그 구조가 **지금 어디까지 성립하고 무엇이 아직 안 되는지**를 적는다.
안 되는 것을 되는 것처럼 그리는 설계도는 그 자체로 사고의 원인이다.

## 두 개의 루프

```
                    ┌──────────────────────────────────────┐
   [루프 A] 검색     │  지식 베이스 (kb/chunks, 102개)        │
   ● 작동함          │  ├── 사람이 읽는 위키  kb/docs/        │
                    │  ├── 라우팅 색인      kb/INDEX.md     │
                    │  └── 벤더 행렬        kb/vendors.yaml │
                    └───────────────┬──────────────────────┘
                                    │ 조회
                    ┌───────────────▼──────────────────────┐
                    │  에이전트 (Claude Code / Gemini CLI / │
                    │  Codex / 로컬 모델)                   │
                    └───────────────┬──────────────────────┘
                                    │ 사용 흔적
   ┌────────────────────────────────▼──────────────────────┐
   │  질의 로그  →  held-out test 세트  →  T-14 게이트       │  ← 지금 0건
   │                     │                                  │
   │                     ▼                                  │
   │  optimize.py: 진단 → 성찰 요청 → 후보 채점 → 채택       │  ← 하네스 완성
   └───────────────────────────────────────────────────────┘

   [루프 B] 지침    프로젝트 결과 → 지침 유효성 → 지침 개선
   ○ 점수 함수 없음  **아직 닫히지 않았다. §4 참조**
```

## 1. 루프 A — 검색 (작동함)

**점수 함수**: held-out nDCG@10. `tools/eval_retrieval.py`가 낸다.
**최적화 대상**: `retrieval_questions`, 확장하면 `tags`·`use_cases`·`context_header`.
**최적화기**: `tools/optimize.py`. GEPA 형태(실패 성찰 + Pareto), **LLM을 호출하지 않는다.**

한 바퀴는 `docs/OPTIMIZATION-LOOP.md`에 있다. 핵심 성질 세 가지:

1. **하네스가 불변이고 모델이 교체 가능하다.** 성찰 요청을 파일로 내보내고 후보를
   파일로 받는다. Claude Code든 Gemini CLI든 로컬 모델이든 같은 요청을 쓴다.
   여러 모델을 같은 요청에 붙이면 Pareto 프런티어가 넓어진다.
2. **dev로 최적화하고 test로 확인한다.** `split` 필드가 경계이고
   `load_dev()`가 그 경계를 코드로 강제한다.
3. **안전장치가 절반이다.** 누출 거부, test 차단, 부수 피해 측정, 출처 표기.
   `optimize.py selftest`가 이것들이 실제로 발화하는지 확인하고 게이트가 그걸 돌린다.

**지금 이 루프를 돌려 채택하면 안 되는 이유**: `test` 세트가 0건이다.
dev 40여 건은 전부 AI가 지어냈고 설정 선택에 이미 쓰였다(`docs/TEST-RESULTS.md` §12.8).
질의도 후보도 같은 상상에서 나오면 개선처럼 보이는 것이 개선이 아니다.

## 2. 멀티 벤더 — 지침이 어디서 통하는지 기록한다

`kb/vendors.yaml`이 (기능 × 벤더) 28셀을 갖고, 각 셀은 **어떻게 확인했는지**를 함께 적는다.

| 등급 | 뜻 |
|---|---|
| `internal-test` | 사내에서 실행해 확인 (최고) |
| `primary` | 벤더 공식 문서·사양 원문 |
| `secondary` | 2차 출처. 인용 시 등급을 밝힐 것 |
| `unknown` | 확인하지 않음 |

현재 확인 5 / 2차 9 / 미확인 14. Claude Code는 미확인 0이고 Gemini CLI는 5다 —
**이 KB가 어디서 얇은지가 그대로 보인다.**

T-19가 강제하는 것은 커버리지가 아니라 **근거 표기**다. `unknown`은 통과하고
`support: yes` + `verified: unknown`은 막힌다. 모르는 걸 모른다고 적는 건 정상이고,
확인 안 한 걸 확인한 것처럼 적는 게 사고다.

## 3. 프로젝트가 이걸 어떻게 쓰는가

벡터 DB 없이도 저장소만 clone하면 쓸 수 있다 — 그게 에이전트 표면을 만든 이유다.

```
1단계 discovery   skills/ainative-kb/SKILL.md 의 name/description
2단계 activation  kb/INDEX.md 를 grep — 한 줄에 한 청크
3단계 execution   kb/chunks/<id>.md 전문
```

프로젝트 쪽에서 할 일:
- `AGENTS.md`에 이 KB를 참조로 건다 (벤더 중립)
- 답을 인용할 때 `chunk_id`와 `confidence`를 함께 남긴다
- 못 찾은 질의를 모은다 → **그게 루프 A의 연료다**

마지막 줄이 이 시스템의 실질적인 계약이다. 프로젝트가 질의 로그를 돌려주지 않으면
루프 A는 AI가 상상한 질의 위에서만 돈다.

## 4. 루프 B — 지침 유효성 (아직 닫히지 않음)

**여기가 이 시스템의 다음 관문이고, 지금은 정직하게 비어 있다.**

루프 A가 성립하는 이유는 점수 함수가 있기 때문이다. 지침에는 그게 없다 —
"이 운영 규칙을 따르면 프로젝트가 실제로 나아지는가"를 잴 방법이 지금 없다.

점수 함수 없이 최적화 루프를 붙이면 **좋아 보이는 방향으로만 움직이고 아무도
그게 틀렸는지 모른다.** 그래서 붙이지 않았다.

닫으려면 필요한 것, 쉬운 순서로:

| 단계 | 신호 | 필요한 것 |
|---|---|---|
| 1 | **준수 여부** | 프로젝트가 지침대로 설정했는지 자동 점검 (린트 성격). 결과와 무관하게 지금 잴 수 있다 |
| 2 | **채택 여부** | 어느 지침이 실제로 읽히고 인용되는가. 프로젝트가 `chunk_id`를 남기면 나온다 |
| 3 | **결과 상관** | 지침을 따른 프로젝트가 따르지 않은 프로젝트보다 나았는가. **프로젝트 수가 있어야 성립한다** |

1단계는 프로젝트가 몇 개든 지금 만들 수 있고, 3단계는 수십 개가 모여야 의미가 생긴다.
**순서를 건너뛰지 말 것** — 3단계 없이 지침을 자동 최적화하면 근거 없이 문서를 흔들게 된다.

그전까지 **지침은 사람이 쓰고 사람이 검토한다.** 기계는 검색만 돕는다.

## 5. 지금 상태 요약

| 축 | 상태 | 막는 것 |
|---|---|---|
| 구조 품질 | ● 게이트 9종 차단 | T-03/04/05/08/13/16/17/18/19 |
| 어휘 검색 | ● 전면 측정 + 회귀 차단 | T-14 |
| dense/hybrid | ○ 미측정 | 벡터 DB 적재. 경로는 `--dense-runs`로 열려 있음 |
| 최적화 루프 | ◐ 하네스 완성, 채택 보류 | `test` 세트 0건 |
| 멀티 벤더 | ◐ 행렬 완성, 확인 5/28 | 사내 실행 확인 |
| 지침 유효성 | ○ 점수 함수 없음 | 프로젝트 신호 |

**한 문장으로**: 구조와 검색은 검증됐고, 내용은 부분 검증이며,
지침이 실제로 도움이 되는지는 아직 아무도 재지 않았다.
